# AlgorithmusIterationis

## Introduction
"Algorithmus" means "algorithm". "Iterationis" means "of iteration". Put them together, and AlgorithmusIterationis helps you improve at something by iteratively reviewing mistakes, so you don't repeat them.

## Distinguishing Features
- **powerful tag-filtering syntax:** the handful of commands for filtering and sorting is enough to quickly create any Queue you want and review it
- **pragmatic review options:** enter the time you have free, and it creates a Queue of the most urgent errors using the `gf` (greedy-filter) command
- **cram-mode:** temporarily multiply the urgency of Errors relevant to an upcoming exam with the `m` command, so they take priority over other Errors
- **free-as-in-freedom:** your data is stored in `JSON` files, so you can edit it with another program, and are not forced to keep using AlgorithmusIterationis if you decide that you don't like it
